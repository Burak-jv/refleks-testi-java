Refleks Testi Oyunu (Java)

Konsol üzerinden oynanan bir refleks ölçüm uygulamasıdır.  
Kullanıcıdan rastgele bir süreden sonra "ŞİMDİ!" komutu geldiğinde mümkün olan en kısa sürede Enter'a basması beklenir.

---

## Özellikler

-  Oyuncu adı girişi
-  Zorluk seviyesi (kolay / zor)
-  5 turluk test ve ortalama süre hesaplama
-  Reaksiyon süresine göre puanlama
-  Erken basma kontrolü (yanlış zamanda Enter’a basarsan uyarı verir)
-  `skorlar.txt` dosyasına otomatik kayıt
-  Gerçek zamanlı skor hesaplama

---

## Gereksinimler

- Java 8 veya üstü
- Java destekli bir IDE (Eclipse, IntelliJ IDEA, NetBeans vs.)
